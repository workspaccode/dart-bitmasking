## 2.0.0

- Initial release as `bitmasking` package
- `Bitmask` class with support for 1–63 bit masks
- Constructors: `Bitmask()`, `fromInt()`, `fromList()`, `fromBitmask()`
- Bitwise operators: `&`, `|`, `^`, `~`
- Shift operators: `<<`, `>>`
- Utility methods: `set()`, `unset()`, `isSet()`, `clear()`, `toList()`, `countSetBits()`, `toString()`
- Index operators: `[]`, `[]=`
- Equality and hashCode support
